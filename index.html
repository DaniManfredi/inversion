Plataformas

Los lugares donde tenés la plata: brokers, exchanges, bancos, billeteras. Escribí el nombre y tocá "+ Agregar": queda disponible en el formulario de carga y en el editor de posiciones. Al renombrar una, se actualizan todas las posiciones que la usan; al eliminarla, elegís a dónde mudar sus posiciones.

Tipo de cambio USD/ARS

Para convertir tus posiciones en pesos a USD. Podés cargar el valor a mano o usar el dólar MEP automático desde data912.

Aportes y retiros

Registrá la plata que entra o sale del portfolio (ahorro que invertís, retiros para gastos). No cargues compras o ventas entre activos. Con esto, los Δ del Resumen, el drawdown y la Evolución miden rendimiento en vez de mezclarlo con aportes. Los montos en ARS se convierten al MEP actual.

Sincronización — GitHub

Guarda tus datos en un archivo dentro de un repo privado de GitHub para ver lo mismo en la notebook, la PC y el celular. Se sincroniza solo al abrir, al editar y al volver a la pestaña. El token queda únicamente en este navegador; las API keys de Gemini y Finnhub no se suben.

Sin configurar: los datos viven solo en este navegador.

Cómo crear el repo y el token
  1. En GitHub creá un repo privado vacío, por ejemplo portfolio-data.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → ese repo. Permissions → Repository → Contents: Read and write. Vencimiento: el que prefieras.
  4. Pegá el token y usuario/portfolio-data acá y tocá "Conectar". Repetí lo mismo una vez en cada dispositivo.

Backup

Tus datos quedan en localStorage del navegador (y en GitHub si activaste la sincronización). Exportá un JSON de vez en cuando como respaldo extra.

"Borrar historial" elimina solo los snapshots de evolución, no toca tus posiciones.

Noticias — Gemini API

La pestaña Noticias usa Gemini con Google Search para buscar novedades de tus activos. La key se guarda solo en este navegador y NO se incluye en los backups exportados. Conseguila gratis en aistudio.google.com/apikey.

Market cap — Finnhub API

La vista "Por capitalización" de Acciones usa Finnhub para traer el valor de mercado de cada empresa. La key se guarda solo en este navegador y NO se incluye en los backups. Conseguila gratis en finnhub.io/register.

Fuentes

De dónde sale cada cotización.

  • Cripto → api.coingecko.com (principal)
  • Cripto fallback → api.binance.com
  • Acciones USA → data912.com/live/usa_stocks
  • CEDEARs ARS → data912.com/live/arg_cedears
  • Acciones AR → data912.com/live/arg_stocks
  • Dólar MEP → data912.com → fallback dolarapi.com → fallback criptoya.com
  • Market cap → finnhub.io/api/v1/stock/profile2 (acciones AR vía su ADR)
